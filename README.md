# Desert Drifter

Arcade desert-road game (Phaser 3) — drive, dodge, survive the UFO.

**Play:** [https://thomasmeston.github.io/DesertDrifter/](https://thomasmeston.github.io/DesertDrifter/)

## Local

```bash
npx --yes serve .
# or: python -m http.server 8080
```

Open the local URL (not `file://`) so assets load correctly.
